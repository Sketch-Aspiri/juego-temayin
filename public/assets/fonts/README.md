# Tipografías de la portada

Se incluyen los archivos originales de [Lilita One](https://github.com/google/fonts/tree/main/ofl/lilitaone) (Juan Montoreano) para el título y los botones, y de [Bree Serif](https://github.com/google/fonts/tree/main/ofl/breeserif) (TypeTogether) para el subtítulo.

Ambas se distribuyen con su licencia SIL Open Font License 1.1 completa en esta carpeta. No se modifican los archivos de fuente. Se sirven desde el juego mediante `@font-face`, sin peticiones a servicios de fuentes externos durante la partida.
